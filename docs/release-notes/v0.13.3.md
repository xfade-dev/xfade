# xfade v0.13.3

**Release Focus**: Single-master-key encrypted vault — at most one OS Keychain entry for all providers.

---

## What's New in v0.13.3

### Single-Master-Key Encrypted Vault (`VaultStore`)
- **One Keychain Item Total**: Instead of creating a separate OS Keychain entry for every provider, `xfade` now stores **only one** 256-bit master key (`xfade/master_key`) in the OS Keychain and encrypts all provider API keys with AES-256-GCM inside `~/.config/xfade/vault.enc` (`0600` permissions).
- **Zero-Friction Upgrades & Probing**: Adding, editing, or probing 20+ providers never creates extra Keychain items or triggers N separate authorization dialogs.
- **Automatic Lazy Migration**: Existing per-provider Keychain entries are automatically migrated into `vault.enc` on first read (or via `xfade doctor --security --fix`) and cleaned up from the Keychain.

## Upgrade Instructions

### Homebrew (macOS & Linux)
```bash
brew update && brew upgrade xfade-dev/xfade/xfade
```

### One-Line Script
```bash
curl -fsSL https://xfade.sh | sh
```

### Self-Update
```bash
xfade self-update
```
