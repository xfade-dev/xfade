# xfade v0.13.1

**Release Focus**: Cross-tool circuit isolation and smoother macOS Keychain ergonomics across upgrades.

---

## What's New in v0.13.1

### 1. Per-Tool Circuit Isolation
- Circuit-breaker keys are now scoped by `(tool, provider_id)` (`circuit_key(tool, id)`), and router health checks receive `&Provider`.
- Two tools sharing the same provider name (e.g. `claude/devops` and `pi/devops`) maintain independent circuit states and never mix credentials.

### 2. macOS Keychain Upgrade Ergonomics & Doctor Fix
- Added `keychain_allow_all` configuration (`xfade config set keychain_allow_all true|false`, default `true`) to avoid repeated macOS Keychain authorization prompts when Homebrew upgrades replace the binary cdhash.
- `KeyringStore` caches retrieved secrets in memory for the store lifetime, reducing redundant OS keychain reads.
- `xfade doctor --fix` refreshes Keychain ACLs for active and routed credentials.

---

## Upgrade Instructions

### Homebrew (macOS & Linux)
```bash
brew update && brew upgrade xfade-dev/xfade/xfade
```

### One-Line Script
```bash
curl -fsSL https://xfade.sh | sh
```

### Self-Update
```bash
xfade self-update
```
