# xfade v0.14.5

**Release Focus**: Sign macOS GUI bundles (`ad-hoc`), fix the OpenClaw tab serialization mismatch, and add a real `<select>` dropdown for probed models in `xfade-gui`.

---

## What's New in v0.14.5

### macOS GUI Signing & CI Gate
- **Ad-Hoc Signing**: Configured `bundle.macOS.signingIdentity: "-"` in `tauri.conf.json` so `.app` and `.dmg` bundles include sealed resources (`Contents/_CodeSignature`) instead of failing Gatekeeper as "damaged" on Apple Silicon.
- **CI Signature Verification**: Added `codesign --verify --deep --strict` to the `gui` release job in `.github/workflows/release.yml`.

### GUI Fixes
- **OpenClaw Tab Fix**: Fixed `"openclaw"` → `"open-claw"` in `types.ts` and `ProvidersPage.tsx` to match `ToolKind` kebab-case serialization.
- **Probed Model Dropdown**: Replaced `<datalist>` in `ProviderForm.tsx` with a native `<select>` dropdown alongside the custom model input so probed `/v1/models` choices work reliably in macOS WKWebView.

## Upgrade Instructions

### Homebrew (macOS & Linux)
```bash
brew update && brew upgrade xfade-dev/xfade/xfade
```

### One-Line Script
```bash
curl -fsSL https://xfade.sh | sh
```

### Self-Update
```bash
xfade self-update
```
