# xfade v0.12.3

**Release Focus**: TUI forms tell you what to fill in.

In v0.12.2 the global defaults form asked for `Secrets` and `API` as free text, which left first-time users guessing. This patch turns every fixed-choice field into a visible selector.

---

## What's New in v0.12.3

### 1. Choice fields show every option
```
Secrets:  (•) keyring  ( ) file
API:      (•) openai-completions  ( ) anthropic-messages
Protocol: (•) auto  ( ) chat  ( ) messages  ( ) responses
```
- `←/→` or Space changes the selection; Backspace resets to the default.
- **API** defaults to `openai-completions`, which is what Pi, Oh My Pi and OpenClaw already used when it was unset. Choose `anthropic-messages` for gateways that speak `/v1/messages`. Other tools ignore this field.
- Saving now writes the selected API type explicitly.

### 2. Per-field hints
Focusing a field in the global form shows what it does, e.g. `keyring` = OS keychain, `file` = `secrets.json` (0600) for servers/SSH. Changing Secrets reminds you that it applies after restart and that existing keys are not migrated.

### 3. Fix: focused field clipped in narrow panes
Option rows can wrap in narrow panes; scrolling now accounts for wrapped rows so the field you are editing stays visible.

```bash
curl -fsSL https://xfade.sh | sh
```

