# xfade v0.12.1

**Release Focus**: CLI Command Categorization & Interactive TUI Modernization.

This patch release significantly enhances developer experience and terminal visual aesthetics, introducing structured CLI help categorization and an adaptive dual-pane TUI dashboard.

---

## What's New in v0.12.1

### 1. Structured CLI Help Categorization
`xfade --help` now organizes 34 subcommands into 6 logical, easy-to-navigate functional categories modeled after `gh` and `cargo`:
- **CORE ROUTING & SWITCHING**: `use`, `run`, `ls`, `status`, `current`, `tui`
- **GATEWAY & TRAFFIC GOVERNANCE**: `serve`, `proxy`, `model-map`, `pricing`, `stats`, `sessions`
- **SECURITY & TRUST**: `doctor`, `audit`, `egress`, `handover`
- **CONFIGURATION & ASSETS**: `add`, `edit`, `rm`, `import`, `presets`, `config`, `backup`
- **TOOL LAUNCHERS (Zero-config instant run)**: `claude`, `codex`, `opencode`, `aider`, `pi`, `omp`, `cline`, `hermes`, `openclaw`
- **GENERAL**: `self-update`, `completion`, `project`

All existing CLI invocations, flags, and subcommand help screens (`xfade <cmd> --help`) remain 100% backward compatible.

### 2. Adaptive Dual-Pane TUI Dashboard (`xfade tui`)
- **Dual-Pane Viewport**: On terminals with width ≥ 70 and height ≥ 18, `xfade tui` expands into an interactive dual-pane dashboard:
  - **Left Pane (38%)**: Fast provider navigation list featuring active indicators (`*`), latency badges (`⚡ 142ms` / `● 320ms`), and 7-day availability percentages (`99% ok`).
  - **Top-Right Card**: Selected provider details including endpoint Base URL, protocol format (`Chat` / `Messages` / `Responses`), default model, multi-slot role mappings (`haiku`/`sonnet`/`opus`), and OS keychain reference (`ref:<id>`).
  - **Bottom-Right Card**: Gateway traffic health and telemetry: security state (`[GUARDED]`), 7-day request volume, error rates, average latency, and micro-dollar estimated cost (`$X.XXXX (est)`).
- **Graceful Responsive Degradation**: Terminals below 70 columns or 18 rows automatically degrade to a compact, single-column view without text truncation or overflow.
- **Enhanced Keyboard Navigation**:
  - `Space` or `Enter` to switch the active provider with an animated crossfade gradient slider.
  - `Tab` / `Shift+Tab` (`BackTab`) to cycle forward and backward across all supported coding tools.
  - `BackTab` field navigation in provider edit mode.
- **Terminal Safety & Robustness**:
  - Unconditional terminal cleanup ensuring raw mode is disabled, alternate screen is exited, and cursor visibility is restored even upon unexpected panics.
  - Isolated latency probes preventing probe results from leaking across tools when switching tabs.
  - Saturated token counting arithmetic preventing integer overflow on high-volume usage records.

## Upgrade Instructions

### Homebrew (macOS & Linux)
```bash
brew update && brew upgrade xfade-dev/xfade/xfade
```

### One-Line Script
```bash
curl -fsSL https://xfade.sh | sh
```

### Self-Update
```bash
xfade self-update
```
