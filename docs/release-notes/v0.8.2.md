# xfade v0.8.2

Two new tools join the roster: **Hermes Agent** and **OpenClaw** — plus the provider-management UI now covers Cline too.

---

## New

### Hermes Agent adapter

`xfade` can now switch providers for [Hermes Agent](https://github.com/linke-ai/hermes-agent-team) (`~/.hermes/config.yaml`). A third-party endpoint is written as a `model:` block:

```yaml
model:
  provider: custom
  default: kimi-k2.5
  base_url: https://api.moonshot.cn/v1
  api_key: sk-...
```

Switching back to official restores the previously captured `model:` block, leaving every other `config.yaml` field untouched.

```bash
xfade add kimi --tool hermes --base-url https://api.moonshot.cn/v1 --key sk-... --set model=kimi-k2.5
xfade use kimi --tool hermes
```

### OpenClaw adapter

`xfade` can now switch providers for OpenClaw (`~/.openclaw/openclaw.json`). A custom provider is registered under `models.providers.xfade` and pinned as the agent's primary model:

```json5
{
  agents: { defaults: { model: { primary: "xfade/kimi-k2.5" } } },
  models: { providers: { xfade: {
    baseUrl: "https://api.moonshot.cn/v1",
    apiKey: "sk-...",
    api: "openai-completions",
    models: [{ id: "kimi-k2.5", name: "kimi-k2.5" }],
  } } },
}
```

The config is read as JSON5 (comments, trailing commas, unquoted keys), so hand-edited configs won't break the import. Switching back to official removes the `xfade` provider and restores the captured primary.

```bash
xfade add kimi --tool openclaw --base-url https://api.moonshot.cn/v1 --key sk-... --set model=kimi-k2.5
xfade use kimi --tool openclaw
```

### Presets

OpenRouter / Kimi (Moonshot) / DeepSeek presets and the local-proxy preset (`http://127.0.0.1:24860/v1`) are available for both tools.

### GUI

The provider-management UI now lists Cline (previously missing), Hermes Agent, and OpenClaw; the tray menu now shows all nine supported tools.
