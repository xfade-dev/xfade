# xfade v0.14.7

**Release Focus**: Full **Antigravity CLI (`agy`)** support and native **Google Gemini (`/v1beta`)** proxy protocol & bidirectional transcoding.

---

## What's New in v0.14.7

### Antigravity CLI (`agy`) Integration
- **Adapter & Config Management**: Added `ToolKind::Agy` (`agy` / `antigravity`) and `AgyAdapter` to manage `modelProvider`, `model`, and `customModelsConfig` in `~/.gemini/antigravity-cli/settings.json` while restoring the original OAuth state on official switch.
- **Zero-Disk Launch (`xfade agy` / `xfade run agy`)**: Launches `agy` with inline `--settings`, `GOOGLE_GEMINI_BASE_URL`, and `GEMINI_API_KEY` without modifying on-disk configuration.
- **Presets & UI Parity**: Added `official`, `google-ai-studio`, and `local-proxy` presets for `agy`, tightened TUI tab spacing for 10 tools in 80 columns, and synced `agy` / `gemini` types to `xfade-gui`.

### Native Gemini `/v1beta` Proxy & Protocol Transcoding
- **Gateway Routing & Auth**: Added `ProviderProtocol::Gemini`, `/v1beta/models/{*rest}` routes, and `x-goog-api-key` local token authentication.
- **Bidirectional Conversion**: Added `Gemini ↔ Chat` request, response, and SSE streaming converters (`convert_gemini.rs`) supporting `systemInstruction`, `contents`/`parts`, `functionCall`/`functionResponse`, and `usageMetadata` accounting — enabling `agy` to route to OpenAI/Anthropic/Bedrock upstreams and other tools to route to Gemini upstreams.

## Upgrade Instructions

### Homebrew (macOS & Linux)
```bash
brew update && brew upgrade xfade-dev/xfade/xfade
```

### One-Line Script
```bash
curl -fsSL https://xfade.sh | sh
```

### Self-Update
```bash
xfade self-update
```
