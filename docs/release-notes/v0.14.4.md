# xfade v0.14.4

**Release Focus**: Fix the macOS GUI release build (`tauri-build` 2.7.6 + `commands.rs` compile fixes).

---

## What's New in v0.14.4

### GUI Release Build Fix
- **`tauri-build` 2.7.6**: Upgraded `tauri-build` from `2.6.3` to `2.7.6` so Cargo's `build/<pkg>/<hash>/out` layout resolves `target/release` correctly instead of `target/release/build` during sidecar `copy_binaries`.
- **GUI Command Compile Fixes**: Imported `RequestLog` in `crates/gui/src-tauri/src/commands.rs` for `recent_logs` and annotated the `update_provider` `spawn_blocking` closure return type.

---

## Upgrade Instructions

### Homebrew (macOS & Linux)
```bash
brew update && brew upgrade xfade-dev/xfade/xfade
```

### One-Line Script
```bash
curl -fsSL https://xfade.sh | sh
```

### Self-Update
```bash
xfade self-update
```
