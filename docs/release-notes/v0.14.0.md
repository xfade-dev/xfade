# xfade v0.14.0

**Release Focus**: Bring `xfade-gui` to full feature parity with `xfade tui` while hardening `xfade-core`, daemon lifecycle management, and Tauri security boundaries.

---

## What's New in v0.14.0

### GUI TUI Parity
- **Latency & Model Probing**: Probe TCP latency and `/v1/models` catalogs directly from `ProvidersPage` (`Probe` / `Probe All`) and `ProviderForm` (including unsaved form overrides during edit).
- **Direct Mode & Protocol Support**: Switch providers in `Direct` mode (with explicit disk-key warning), select provider protocols (`chat` / `messages` / `responses`), and pick probed models via autocomplete.
- **Routes & Model Map**: Manage per-route upstream models and route priority in `RoutesEditor`, plus `alias → provider=upstream_model` rules and `models-merge` in `ModelMapEditor`.
- **Security Doctor & Settings**: Inspect `TrustState` and run `SecurityDoctorPanel` fixes from the GUI, toggle `keychain_allow_all` live, and configure the global `api` dialect.
- **Daemon & Sidebar Status**: Live sidebar proxy status + restart button, external/unmanaged proxy detection, and `Stop` vs `Uninstall` separation.

### Core, Security & CI
- **Security Hardening**: Enforced Tauri CSP (`connect-src 'self' ipc: http://ipc.localhost`), removed `shell:allow-execute`, disallowed `current_exe()` sidecar fallback in GUI, and guarded NUL bytes / keyring rollback in `set_password_macos_allow_all`.
- **Core Refactors**: Shared `probe_target`/`probe_latency` with CLI, added `SecretStore::normalize_key_acl` to avoid redundant `vault.enc` re-encryption, and added Linux `systemctl --user daemon-reload`.
- **CI**: Upgraded GitHub Actions workflows to Node 24-compatible actions.

## Upgrade Instructions

### Homebrew (macOS & Linux)
```bash
brew update && brew upgrade xfade-dev/xfade/xfade
```

### One-Line Script
```bash
curl -fsSL https://xfade.sh | sh
```

### Self-Update
```bash
xfade self-update
```
