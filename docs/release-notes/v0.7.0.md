# xfade v0.7.0

> **Switch models without dropping the beat.** xfade is a local control plane between your AI coding client and any provider, so you can hot-swap models, gateways, and local endpoints without restarting your session.

---

## The headline: zero-restart hot-swapping

You are deep in a Claude Code refactor, tokens are burning, and `/model` only speaks Anthropic. With xfade you do not leave your terminal — one command reroutes the local gateway and the *next request* goes to DeepSeek, Kimi, OpenRouter, or your local MLX box:

```bash
xfade proxy use kimi,deepseek   # primary -> fallback, re-read on every request
```

No restart. No dropped context. The proxy converts Anthropic <-> OpenAI both ways, including streaming tool-calls, so the client never notices the upstream changed.

## One config, six clients

`xfade` writes each client's own config (settings.json, config.toml, opencode.json, .aider.conf.yml, Pi/OMP models), stores keys in the system keyring, and auto-backs-up before every switch:

```
claude-code | codex | open-code | pi | oh-my-pi | aider
```

A shared **general config** (base_url / model / api / api_key) means you set the gateway once and every tool inherits it — a provider's explicit values always win.

## Also new

- **TUI** (`xfade tui`): a Ratatui crossfader to browse providers with `j/k`, `Enter` to switch.
- **GUI Settings** page: secrets backend, shared base_url/model/api, global API key.
- **`xfade self-update`**: pull the latest release in one command.
- **One-line install**: `curl -fsSL https://xfade.sh | sh` (macOS / Linux, aarch64 + x86_64), plus a Homebrew tap.

## Breaking changes

- **Renamed from `agent-switch` to `xfade`.** Binary, config dir (`~/.config/xfade`), and keyring prefix (`xfade/...`) all renamed. Existing keyring entries under the old `agent-switch/` prefix are migrated automatically on first run — no action needed.
- Protocol conversion is now **bidirectional** (Anthropic <-> OpenAI) rather than one-way.

## Install

```bash
brew tap xfade-dev/homebrew-xfade && brew install xfade
# or
curl -fsSL https://xfade.sh | sh
```
