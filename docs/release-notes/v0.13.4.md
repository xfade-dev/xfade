# xfade v0.13.4

**Release Focus**: Circuit breaker & upstream jitter resilience — fewer false-positive trips and faster recovery on transient upstream hiccups.

---

## What's New in v0.13.4

### Circuit Breaker & Upstream Jitter Resilience
- **Relaxed Default Thresholds**: Updated `CircuitBreakerConfig::default()` (and `FAIL_THRESHOLD` / `COOLDOWN_SECS`) to `failure_threshold = 5`, `success_threshold = 1`, `timeout_seconds = 15`, `error_rate_threshold = 0.9`, and `min_requests = 20`.
- **Same-Route Transient Jitter Retry**: Added a 150ms single-retry before recording a circuit failure on pre-commit stream drops (`stream_ended_before_commit`, `upstream_read_error`) and single-route transport errors.
- **Accurate Error Accounting & 503 Feedback**: `403 Forbidden` passthrough errors no longer count against the circuit breaker; when all routes are cooling down, the proxy returns a structured JSON `503` (`circuit_open`) with a `Retry-After` header and records it in `request_logs`.
