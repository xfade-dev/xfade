# xfade v0.15.0

**Release Focus**: Built-in Model Map templates, automatic upstream `/v1/models` matching, and named Profile switching across **Core / CLI / TUI / GUI**.

---

## What's New in v0.15.0

### Model Map Templates & Auto-Mapping
- **4 Built-in Templates**: `claude-code-standard`, `codex-standard`, `agy-gemini`, and `cost-saver` (plus custom templates from `~/.config/xfade/model_map_templates.json`).
- **Three-Tier Upstream Matching**: `resolve_template_for_provider` matches discovered `/v1/models` catalogs by exact/family patterns (`ProbeExact`), capability tier keywords (`ProbeTier`), or static vendor defaults (`Fallback`).

### Named Model Map Profiles
- **Instant Profile Switching**: Save snapshots of `model_mappings` to `model_map_profiles` and switch between them (`Replace` or `Merge`) in a single transaction with zero proxy restart required.

### CLI, TUI & GUI Support
- **CLI**: `xfade model-map template ls|apply [--probe] [--dry-run] [--save-profile]` and `xfade model-map profile ls|save|use|rm`.
- **TUI**: Press `t` in the Model Map screen (`m`) to preview/apply templates (and `p` to probe), or press `p` in the Model Map list to switch/save/delete profiles.
- **GUI**: Profile quick-switch bar + **Apply Template…** wizard in `ModelMapEditor` with live `/v1/models` probing, source badges, and autocomplete.

## Upgrade Instructions

### Homebrew (macOS & Linux)
```bash
brew update && brew upgrade xfade-dev/xfade/xfade
```

### One-Line Script
```bash
curl -fsSL https://xfade.sh | sh
```

### Self-Update
```bash
xfade self-update
```
