# xfade v0.8.1

Patch release: Codex auth regression, opencode model shorthand, and the `serve install` daemon fix.

---

## Fixes

### Codex 401 "No api key passed in"

Codex ≥0.155 treats a third-party provider with neither `env_key` nor `requires_openai_auth` as unauthenticated and drops the Authorization header, so gateways answered `401 No api key passed in`. xfade now writes `requires_openai_auth = true`, so Codex authenticates with the `OPENAI_API_KEY` that xfade puts in `~/.codex/auth.json`.

### `xfade serve install` failed with "daemon not installed"

`install` called `unload()`, which removed the plist it had just written — so the following `load()` couldn't find it. The unload path is now split into `unload_job` (unload only, no file removal) + `unload` (unload + remove); `install` reloads without deleting the plist. `serve status` also now prints the host.

## New

### opencode `--set model=<id>` shorthand

```bash
xfade add office --base-url https://gw.example/v1 --key sk-... \
    --set model=deepseek-v4-flash --tool opencode
```

Equivalent to the verbose `--set 'models={"deepseek-v4-flash":{"name":"deepseek-v4-flash"}}'`.
