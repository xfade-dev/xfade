# xfade v0.8.0

> **Switch models without dropping the beat.** xfade is a local control plane between your AI coding client and any provider, so you can hot-swap models, gateways, and local endpoints without restarting your session.

---

## The headline: `xfade` is now a crossfader

Bare `xfade` opens an interactive TUI — per-tool tabs, a fader to switch providers, health badges from parallel probe-all, and inline edit:

```
┌ xfade ──────────────────────────┐
│ [claude-code] [codex] [open-code] ...
│  kimi          ● healthy
│  deepseek      ● healthy
│  local-mlx     ○ unreachable
│  ◄─────────●──────────►
└─────────────────────────────────┘
```

`j`/`k` (or arrow keys) to browse providers, `Enter` to switch, `Tab` to hop between tools, `e` to edit inline. In non-TTY environments (scripts, pipes) bare `xfade` degrades to a plain provider list, so automation stays safe.

## Seven clients now — hello, Cline

```
claude-code | codex | open-code | pi | oh-my-pi | aider | cline
```

The new Cline adapter writes the built-in openai-compatible entry (Cline CLI dispatches provider clients by built-in id) — verified end-to-end on Cline CLI 3.0.62.

## Claude Code per-slot models

Pin a different model for each of the `opus` / `sonnet` / `haiku` slots — useful when a gateway only maps some of them:

```bash
xfade add my-gw --tool claude-code --base-url https://gw.example \
    --sonnet-model deepseek-chat --haiku-model deepseek-chat
```

Written as `ANTHROPIC_DEFAULT_*_MODEL`. Rejected on non-Claude tools instead of being silently ignored.

## Also new

- **`xfade self-update`**: pull the latest release in one command.
- **Protocol conversion hardening**: codex Responses↔Chat conversion chain incl. tool round-trip; OpenAI→Anthropic stream compliance (content_block_stop payload, monotonic block indices, lazy text block).
- **Integration fixes** (real-machine verified): bare-host `base_url` normalized with `/v1`; 502 on non-JSON 2xx upstream; `_original_*` capture/restore no longer drops codex model / cline `lastUsedProvider`.
- **Internal**: TailStream merge, preset dedup, dead API cleanup.
