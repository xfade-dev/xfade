# xfade v0.14.3

**Release Focus**: Polish `xfade tui` with faster keyboard shortcuts, Cyan → Magenta gradient hotkey highlights, cache hit observability, and full `Edit` / `Config` form parity.

---

## What's New in v0.14.3

### TUI Shortcuts & Help Overlay
- **Direct Navigation**: Press `1`–`9` to jump straight to any tool tab, `h`/`l` (`←`/`→`) to cycle tools in list mode, `Home`/`End`/`G` to jump to the first/last provider, and `R` to refresh providers and stats.
- **Shortcuts Overlay**: Press `?` from the provider list to open a centered keyboard shortcuts reference modal.

### Visual Polish & Metrics
- **Rounded Borders & Protocol Badges**: Panels use `BorderType::Rounded` with `Cyan` focus borders, and each provider row displays a color-coded protocol badge (`[msg]`, `[resp]`, `[chat]`).
- **Gradient Footer Hotkeys**: Footer shortcuts use the signature Cyan → Magenta gradient with bold underlined single-character lowercase keys (`a`, `e`, `d`, `t`, `p`, `m`, `r`, `g`, `q`).
- **Cache Hit Metrics**: `Gateway & Traffic Health` now displays `Cache: <read> (<hit>% hit) · <write>` when prompt caching is active.

### Form Parity
- **Edit Protocol**: `Edit` (`e`) now includes the `Protocol` selector (`chat` / `messages` / `responses`).
- **Global TTFT Timeout**: `Config` (`g`) now includes `TTFT (s)` (`ttft_timeout_secs`, blank = 90s default).

## Upgrade Instructions

### Homebrew (macOS & Linux)
```bash
brew update && brew upgrade xfade-dev/xfade/xfade
```

### One-Line Script
```bash
curl -fsSL https://xfade.sh | sh
```

### Self-Update
```bash
xfade self-update
```
