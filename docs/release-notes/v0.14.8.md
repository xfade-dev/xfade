# xfade v0.14.8

**Release Focus**: Antigravity CLI (`agy`) instant launch & `customModelsConfig` schema fix, plus Anthropic `tool_use` / `tool_result` null-field sanitization and 400 extra-field self-healing.

---

## What's New in v0.14.8

### Antigravity CLI (`agy`) Fixes
- **Instant Launch Gate**: Added `ToolKind::Agy` to `cmd_run_instant` so `xfade agy <name>` launches directly without falling back to `xfade use`.
- **`customModelsConfig` Map Schema**: Updated `agy_custom_models_config` to emit `customModels` as a model-ID-keyed JSON object (`{ "<model>": { "modelName": ..., "label": ... } }`) matching `agy`'s `jetbox_state_pb.CustomModelsConfig` validation, while keeping `read_current` backward-compatible with array-formatted configs.

### Anthropic `messages` Tool-Block Sanitizer & 400 Rectifier
- **Proactive Null Stripping (`strip_null_extras`)**: Reuses the `is_anthropic_target` JSON parse in `forward.rs` to strip `null`-valued extra keys (such as `toolset_name: null`, `caller: null`) from `messages[*].content[*]` `tool_use` / `tool_result` blocks without touching non-null values, `input` payloads, or prompt-cache byte determinism when nothing is stripped.
- **400 Fallback Rectifier (`rectify_extra_fields_error`)**: On upstream `400 Bad Request` errors matching `extra inputs are not permitted` / `extra fields not permitted` / `additional properties are not allowed`, strips remaining `null` or error-named non-protected `tool_use`/`tool_result` extra fields and retries strictly once on the same provider.

## Upgrade Instructions

### Homebrew (macOS & Linux)
```bash

```

### One-Line Script
```bash
curl -fsSL https://xfade.sh | sh
```

### Self-Update
```bash
xfade self-update
```
