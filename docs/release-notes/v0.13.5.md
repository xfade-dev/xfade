# xfade v0.13.5

**Release Focus**: Fix `502 stream_ended_before_commit` caused by forwarding client `Accept-Encoding` headers to upstreams that compress SSE/JSON responses.

---

## What's New in v0.13.5

### Proxy Upstream Compression Fix
- **Strip `accept-encoding` Upstream**: Added `accept-encoding` to `STRIP_HEADERS` in `crates/core/src/proxy/forward.rs`. Since `reqwest` is configured with `default-features = false` (no gzip/deflate/brotli decompression), forwarding `Accept-Encoding: gzip, deflate, br` caused compressed upstream responses to fail pre-commit SSE/JSON inspection with `502 stream_ended_before_commit` or `502 non_json_response`.
- **Regression Test**: Added `test_client_accept_encoding_not_forwarded_upstream` in `crates/core/src/proxy/mod.rs`.
