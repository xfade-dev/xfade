# xfade v0.12.0

**Milestone Release**: The Vendor-Neutral, Zero-Raw-Key Gateway for AI Coding CLIs.

This release delivers the complete F1–F8 frozen feature set from Strategic Blueprint v0.14: zero-raw-key credential isolation by default, independent per-provider protocols, explicit model mapping, pre-commit failover robustness, three-tier dynamic pricing with live OpenRouter sync, visible trust auditing, cross-platform owner-only DACL file protection, and verified sub-millisecond gateway overhead.

---

## What's New in v0.12.0

### 1. Default Gateway & Credential Isolation (F1 & F2)
- Running `xfade use <provider> --tool <tool>` now defaults to local gateway mode.
- Client configs (`~/.claude/settings.json`, `~/.codex/config.toml`, etc.) are written with virtual local tokens (`xf-tok-*`) pointing to `127.0.0.1:24860`.
- Real upstream API keys are stored exclusively in the OS Keychain (or private encrypted file store) and memory. **Zero raw API keys are written to client config files.**
- Auto-backup of existing client configs before migration, with automatic rollback if health checks fail.
- `--direct` escape hatch preserved for troubleshooting, requiring explicit flag, logged to audit trails, and flagged in security audits.

### 2. Independent Per-Provider Protocols & Transcoding (F4)
- Each upstream provider supports independent protocol configuration: `ProviderProtocol::Chat`, `Messages`, `Responses`.
- Real-time bidirectional streaming transcoding between Anthropic Messages, OpenAI Chat, and Responses protocols with tool-call preservation.
- Heterogeneous cascade failover across different protocols on the same route.

### 3. Explicit Client-to-Upstream Model Mapping (F5)
- Support mapping generic client model names to provider-specific upstream model names:
  `xfade model-map set <provider_id> <client_alias> <upstream_model>`
- CLI suite: `xfade model-map [set|ls|rm|clear]`.
- Stage 2c models-merge automatic bypass to preserve explicit user overrides.

### 4. Robust Failover Before First Byte (F6)
- **Pre-Commit Routing**: Seamless failover on HTTP 200 responses containing JSON error bodies, TTFT timeouts, and connect timeouts.
- **Rate Limit Resilience**: Parses upstream `Retry-After` headers (≤2s) for instant intra-upstream retry before escalating.
- **Zero Stream Replay**: Once the first semantic chunk is emitted to the client, requests are never replayed (preventing duplicated token billing or duplicate tool calls). Interrupted streams synthesize a protocol-native `xfade_stream_interrupted` event and close cleanly.

### 5. Visible Trust & Audit Suite (F7 & T7/T8)
- `xfade doctor --security [--fix]` command suite to audit client configs, tokens, and file permissions with auto-remediation.
- `xfade audit` structured audit log recording client origin, route path, failover trajectories, and token counts without logging prompt contents or keys.
- Outbound egress domain whitelist protecting against SSRF and unauthorized data exfiltration.
- Cross-platform private permissions: Unix `0600` / `0700` + Windows owner/SYSTEM DACL on NTFS, blocking inherited permissions (T7).
- Formal vulnerability response SLA (48h triage, 7d mitigation, 90d disclosure, `security@xfade.dev`).

### 6. Dynamic Three-Tier Pricing & Live Sync (F8 & F8-Ext)
- Micro-dollar ($0.000001) integer arithmetic tracking token costs with prompt cache read and write discounts.
- Three-tier pricing resolution: `Custom Overrides` > `Live OpenRouter Synced Catalog` > `Built-in 2026 Flagship Catalog`.
- CLI suite: `xfade pricing [list|sync|set|rm|reset]`.
- Token and USD cost estimates surfaced in `xfade stats` and `xfade sessions`.

### 7. Verified Performance Benchmarks (F10)
- Automated Criterion microbenchmark suite:
  - Gateway loopback latency overhead: **~0.32 ms** (Direct: 0.032 ms vs Gateway: 0.353 ms).
  - Effective model resolution: **~26 ns**.
  - Micro-dollar price lookup: **~30 ns – 88 ns**.
  - Stream chunk semantic inspection: **< 1 µs**.

## Installation & Upgrade Guide

### Option 1: Homebrew (macOS / Linux)

```bash
# First time install
brew install xfade-dev/xfade/xfade

# Upgrade to v0.12.0
brew update && brew upgrade xfade-dev/xfade/xfade
```

### Option 2: One-Line Installer (`xfade.sh`)

```bash
# Default installation (into ~/.local/bin)
curl -fsSL https://xfade.sh | sh

# Or install / overwrite into system directory
curl -fsSL https://xfade.sh | XFADE_INSTALL_DIR=/usr/local/bin sh

# Reload shell path cache
hash -r   # bash
rehash    # zsh
```

### Option 3: Built-In Self-Update

```bash
xfade self-update
# (If installed in a system directory like /usr/local/bin, run `sudo xfade self-update`)
```

### Option 4: Direct Binary & Sigstore Verification

Download the release archive from [GitHub Releases](https://github.com/xfade-dev/xfade/releases/tag/v0.12.0):

```bash
# Verify release signature and provenance
scripts/verify-release.sh v0.12.0
```
